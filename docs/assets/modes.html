The job says how it may be stopped

restartable

Stop and start again

Same command. State lives outside the process. A model server is this mode.

SIGTERM, then requeue.
cooperative

Save, then resume

On SIGUSR1 the job writes its own checkpoint, then READY, then exits 0.

One signal. No kill to force a save.
atomic

Run to the end

The safe default. A 24 hour job that cannot save is not sliced at midnight.

Once started, never signaled.
